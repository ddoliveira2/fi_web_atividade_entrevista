# fi_web_atividade_entrevista
Projeto desenvolvido como parte de um teste técnico proposto durante um processo seletivo para uma oportunidade profissional. Tem como objetivo demonstrar conhecimentos técnicos.

## Sobre o Projeto

Aplicação web desenvolvida em C# para cadastro e gerenciamento de clientes por meio de um navegador.

## Tecnologias Utilizadas

- C#   
- ASP.NET MVC 
- .NET Framework   
- HTML5
- CSS3
- JavaScript / 
- jQuery 
- Bootstrap
- SQL Server

## Funcionalidades

- Navegação por páginas web
- Formulários de cadastro e edição de clientes
- Listagem responsiva de registros
- Validação de dados
- Interações assíncronas via componentes web

## Arquitetura do Projeto

Arquitetura baseada em camadas (MVC - Model-View-Controller) utilizando bibliotecas do ecossistema .NET.

## Banco de Dados

SQL Server, estruturado com tabelas e procedures/scripts para persistência de dados de clientes.

## Como Executar

1. Clone este repositório.
2. Abra a solução no Visual Studio ou IDE compatível com .NET.
3. Restaure os pacotes NuGet, compile e execute a aplicação.
4. Verifiar path FI.WebAtividadeEntrevista\FI.WebAtividadeEntrevista\bin se a pasta roslyn existe
5. Verificar se a pasta roslyn tem os arquivos corespondentes, se estiver vazia, copiar os arquivos de (packages\Microsoft.CodeDom.Providers.DotNetCompilerPlatform.2.0.1\tools\RoslynLatest)
6. Verificar se o banco de dados se encontra na pasta App_Data é para ter 2 arquivos (BancoDeDados e BancoDeDados_log)
7. Executar aplicação no Visual Studio.
